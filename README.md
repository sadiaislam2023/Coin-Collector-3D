# Coin Collector 3D — Rainbow Runner

A colorful 3D coin-collecting adventure game developed using **Python, PyOpenGL, and OpenGL**. Navigate a vibrant 3D world, collect coins, avoid obstacles, and test your skills across multiple difficulty levels.

## Overview

**Coin Collector 3D (CoinQuest 3D)** is a 3D arcade-style game featuring coin collection, obstacle avoidance, player movement, and time-based challenges. Players can select a difficulty level, earn points by collecting coins, and race toward the destination.

The project demonstrates fundamental game development concepts, including 3D graphics rendering, keyboard input handling, animation, collision detection, and real-time game logic.

## Key Features

- **3D Game Environment:** Explore a colorful game world using a third-person camera.
- **Multiple Difficulty Levels:** Choose Easy, Medium, or Hard for different levels of challenge.
- **Coin Collection and Scoring:** Collect coins and earn points throughout gameplay.
- **Interactive Obstacles:** Navigate around obstacles, including cupcakes, rings, blocks, and stars.
- **Player Health:** Manage health while navigating the course.
- **Jump Mechanics:** Jump to overcome obstacles and movement challenges.
- **Time-Based Gameplay:** Complete challenges within a defined time limit.
- **Progressive Challenges:** Experience longer courses and changing challenges as levels progress.
- **Special Abilities:** Use selected abilities depending on the chosen difficulty level.
- **Interactive Menu:** Select a difficulty level from the introductory screen.
- **Pause and Restart:** Pause gameplay, restart a run, or return to the menu after a game over.

## Game Controls

| Key | Action |
|---|---|
| `A` | Move left |
| `D` | Move right |
| `W` | Move forward |
| `S` | Move backward |
| `Space` | Jump |
| `Esc` | Pause the game |
| `R` | Restart the game |
| `B` | Return to the menu after a game over |

## Special Ability Controls

Special abilities vary depending on the selected difficulty level.

| Key | Ability |
|---|---|
| `F` | Fly |
| `Q` | Speed boost |
| `V` | No-clip |
| `J` | Infinite jump |
| `M` | Coin magnet |
| `H` | Reveal ability in Easy mode |

Not every ability is available in every difficulty mode.

## Difficulty Levels

- **Easy:** Offers a more accessible experience with additional special abilities.
- **Medium:** Provides a greater challenge with a limited selection of special abilities.
- **Hard:** Offers the highest difficulty without the listed special abilities.
